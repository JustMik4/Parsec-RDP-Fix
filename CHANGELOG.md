# Changelog

## 0.1.0 — First public release

- Portable Windows application with automatic administrator permission prompt.
- One-time installed-Parsec startup configuration and saved rollback.
- Same-account, non-elevated Windows Explorer token used to launch the installed host.
- Status, error reporting, and explicit pre-application warnings.
- Light and dark appearance using separate pre-rendered pages.
- Six interface languages: English, Portuguese, Spanish, Russian, Simplified Chinese, and Japanese.
- Automated tests, Windows build, and checksum generation through GitHub Actions.

This is the first public packaging of functionality tested locally during development. Field evidence is limited; reboot persistence and universal compatibility are not guaranteed.
